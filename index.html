Заявка / обращение в ООО «ЭК «ЕД-2»

Приём обращений ведётся через официальную форму «Обращения собственников ЕД2». Нажмите кнопку, заполните поля и отправьте — заявка поступит в ООО «ЭК «ЕД-2» автоматически.

📝 Перейти к форме обращения
Обращения с юридическими требованиями автоматически выделяются для юротдела.

Журнал обращений

Обращения, переданные через Яндекс Форму, обрабатываются в ООО «ЭК «ЕД-2» и отображаются здесь в сводном виде только для тех собственников, которые зарегистрировались на сайте.

Документы по вашему участку

Подписание через Яндекс Форму. Нажмите «Подписать через Яндекс Форму», заполните форму «Подтверждение подписания документов – ЕД2» (ФИО, участок, кадастр, № и дата документа, код подтверждения, файл PDF). Статус «Подписано» появится после подтверждения ООО «ЭК «ЕД-2».
📤 После отправки через Яндекс Форму статус документа автоматически меняется на «Отправлено» (ожидает подтверждения ООО «ЭК «ЕД-2»). Если статус не обновился — нажмите «Я отправил(а) форму» под документом.

Для просмотра документов по вашему участку пройдите регистрацию.
